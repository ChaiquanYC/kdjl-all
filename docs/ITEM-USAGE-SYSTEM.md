## 二、各类型详细使用规则

### 2.1 varyname=1 辅助类（药水）

- **使用对象**: 需选择目标宠物
- **效果**: 解析 `effect` 字段中的 `hp`/`mp` 值，恢复宠物生命/魔法
- **使用场景**: 战斗中使用，在 `Fight_Mod.php` 等战斗模块中处理（非 usedProps.php）
- **PHP文件**:
  - `Fight_Mod.php` — 普通战斗
  - `Fight_Mod_Mobile.php` — 手机版战斗
  - `Fight_ModT.php` — 另一种战斗模块
  - `Challenge_Mod.php` — 挑战模式
  - `fbfight_Mod.php` — 副本战斗
- **限制**: 无特殊限制

### 2.2 varyname=2 增益类（永久属性药水）

- **使用对象**: 固定作用于主战宠物（`user.mbid`）
- **前置检查**:
  - 需要主战宠物存在（`is_array($bb)`）
  - 神圣宠物(wx==7)无法使用非 `__SS__` 标记的道具
  - 非神圣宠物无法使用 `__SS__` 标记的道具
  - 需要数据库行锁（`getLock`）
- **Effect 键详解**:

| Key | 格式 | 效果 | 数据库操作 | 限制 |
|-----|------|------|-----------|------|
| `addexp` | `addexp:(min,max)` | 给主战宠加经验 | 调用 `saveExps()` | 宠物满级时报错 |
| `addczl` | `addczl:数值` | 永久增加成长率 | `userbb.czl += 数值` | 每只宠物只能使用一次（检查 `player_ext.chouqu_chongwu`）；神圣宠物有 `super_jh.max_czl` 上限 |
| `addac` | `addac:数值` | 永久加攻击 | `userbb.ac += 数值` | 无 |
| `addmc` | `addmc:数值` | 永久加防御 | `userbb.mc += 数值` | 无 |
| `addhp` | `addhp:数值` | 永久加HP上限 | `userbb.srchp += 数值` | 无 |
| `addmp` | `addmp:数值` | 永久加MP上限 | `userbb.srcmp += 数值` | 无 |
| `addspeed` | `addspeed:数值` | 永久加速度 | `userbb.speed += 数值` | 无 |
| `addhits` | `addhits:数值` | 永久加命中 | `userbb.hits += 数值` | 无 |
| `addmiss` | `addmiss:数值` | 永久加闪避 | `userbb.miss += 数值` | 无 |
| `weiwang` | `weiwang:数值` | 增加威望 | `player.prestige += 数值` | 无（作用于玩家，非宠物） |
| `add_cq_czl` | `add_cq_czl:数值` | 增加抽取成长点数 | `player_ext.czl_ss += abs(数值)` | 无 |
| `add_zc_jifen` | `add_zc_jifen:数值` | 战场积分倍数 | 写入 `player_ext.buff_status`，格式 `add_zc_jifen:日期,倍数;` | 无 |

### 2.3 varyname=3 捕捉类（精灵球）

- **使用对象**: 战斗中对怪物使用
- **效果**: 尝试捕捉怪物为宠物
- **PHP文件**: `get.Catch.php`
- **限制**: 仅战斗中可用

### 2.4 varyname=4 收集类（彩票/抽奖券）

- **使用对象**: 玩家自身
- **效果**: 购买彩票，获得随机号码
- **流程**:
  1. 检查 `welcome` 表中 `code='ticket'` 的开奖配置
  2. 检查今日是否已开奖（`date('H') >= 配置时间`）
  3. 检查 `effect` 字段必须为 `'ticket'`
  4. 创建 `ticket_YYYYMMDD` 表（如不存在）
  5. 生成随机号码写入表中
- **限制**: 每日开奖时间后不可购买

### 2.5 varyname=5 技能书类

- **使用对象**: 宠物
- **效果**: 宠物学习新技能
- **PHP文件**: `get.Skill.php`（学习）、`get.sjSkill.php`（升级）
- **限制**: 6步校验（详见 `SKILL-SYSTEM.md`）

### 2.6 varyname=6 卡片类（旧版）

- **状态**: 已废弃，无任何实现代码，被 varyname=24 替代

### 2.7 varyname=7 进化类

- **使用对象**: 宠物
- **效果**: 宠物进化材料，消耗后使宠物进化为更高级形态
- **PHP文件**: `jhGate.php`（普通进化）、`superJhGate.php`（神圣进化）、`zhGate.php`（转生进化）
- **流程** (`jhGate.php`):
  1. 查宠物 `bb` 表的 `remakeid`（进化目标宠物ID）、`remakepid`（所需材料propId，`|`分隔多个可选材料）、`remakelevel`（进化等级要求）
  2. 检查背包中是否有对应的 varyname=7 材料
  3. 检查宠物等级 >= 进化等级要求
  4. 检查宠物五行 <= 6（神圣宠物不可普通进化）
  5. 检查进化次数 < 10（`remaketimes`）
  6. 检查宠物未抽取过成长（`chouqu_chongwu`）
  7. 计算新成长率（两种进化方式）：
     - **方式1（style=1）**: `原czl + rand(0.1,0.5) + (当前等级-进化等级)/200`
     - **方式2（style=2）**: `原czl + rand(0.5,1.0) + (当前等级-进化等级)/200`
     - czl >= 50 时增长递减，czl >= 150 时封顶
  8. 更新宠物名字、图片、成长率、进化次数
  9. 扣除材料和1000金币
- **特殊材料**:
  - pid=1221: 固定成长+0.1~0.3
  - pid=1222: 固定成长+0.3~0.6
  - `keepczl:数值` 效果的道具: 保护成长率不超过指定上限
- **限制**: 抽取过成长的宠物不能进化；进化次数上限10次；神圣宠物(wx>6)不能普通进化

### 2.8 varyname=8 合体类

- **使用对象**: 宠物
- **效果**: 宠物融合/合体时的辅助道具
- **PHP文件**:
  - `cmpGate.php` — 宠物合体系统，effect 字段包含合体公式 `hecheng:A:10%,B:4%|addczl:8%|1`
  - `zsGate.php` — 涅槃/转生系统，作为合体材料消耗
  - `Sd_Mod.php` — 合体界面显示
  - `Sd_ComposeMod.php` — 合成界面显示
- **效果**: 合体时提供成功率加成、成长率加成、保护宠物不消失等
- **限制**: 在 usedProps.php 中无逻辑，由合体/涅槃系统独立消费

### 2.9 varyname=9 装备类

- **使用对象**: 固定作用于主战宠物（`user.mbid`）
- **前置检查**:
  - 需要主战宠物存在
  - 检查 `requires` 字段：`lv:等级` 要求宠物等级 >= 指定值；`wx:五行` 要求宠物五行匹配
  - 检查 `postion` 字段确定装备槽位
- **效果**:
  - 将道具ID写入 `userbb.zb` 字段（格式 `槽位:道具ID,槽位:道具ID,...`）
  - 同槽位旧装备自动卸下（`userbag.zbing=0, zbpets=0`）
  - 新装备标记 `userbag.zbing=1, zbpets=宠物ID`
  - 调用 `formatMsgEffect()` 重算装备属性
- **PHP文件**: `usedProps.php`（穿戴）、`zbstrength_Mod.php`（强化）、`zbstrengthGate.php`（强化验证）、`xqhcGate.php`（宝石镶嵌）、`zbxlGate.php`（洗练）、`Zb_Mod.php`（装备界面）
- **限制**: 五行不匹配或等级不够时报错

### 2.10 varyname=10 精炼类（强化材料）

- **使用对象**: 装备
- **效果**: 装备强化时的消耗材料

### 2.12 varyname=12 礼包类（宝箱/礼包）

- **使用对象**: 玩家自身
- **前置检查**:
  - 背包剩余空间 >= 3 格（`maxbag - 已用格数 >= 3`）
  - 背包未满
  - 检查 `requires` 字段的等级要求（`lv:等级`，对比主战宠等级）
- **Effect 键详解**:

| Key | 格式 | 效果 | 限制 |
|-----|------|------|------|
| `needkey` | `needkey:钥匙propId` | 检查背包中是否有对应钥匙，有则扣除1个 | 无钥匙时报错"您没有开启宝箱的钥匙!" |
| `giveitems` | `giveitems:propId1:count1,propId2:count2,...` | 固定掉落所有列出的物品 | 背包空间需 >= 物品种类数 |
| `randitem` | `randitem:propId:count:prob:flag\|...` | 按概率随机获得1个物品。`prob` 为 1/N 概率，`flag`=2 时发系统公告 | 只命中第一个概率命中的物品 |

- **多键组合**: effect 字段可包含多个键，用逗号分隔，如 `needkey:123,giveitems:456:1,789:2`

### 2.15 varyname=15 宠物卵

- **使用对象**: 玩家自身（创建新宠物到背包）
- **前置检查**:
  - 需要数据库行锁（`getLock`）
  - 当前携带宠物数 < 3（遍历 `userbb` 中 `muchang==0` 的宠物计数）
- **Effect 键**:

| Key | 格式 | 效果 |
|-----|------|------|
| `openpet` | `openpet:bb模板ID` | 从 bb 模板创建新宠物 |

- **详细流程**:
  1. 查询 `bb` 表获取模板属性（name, wx, ac, mc, hp, mp, skillist 等）
  2. 随机生成 czl（成长率）: `getCzl(bb.czl)` 从模板范围中随机
  3. 插入 `userbb` 表（level=1, nowexp=0, muchang=0）
  4. 遍历 `skillist`（格式 `技能ID:等级,技能ID:等级,...`），从 `skillsys` 表查询技能属性，插入 `skill` 表
  5. 头像图片: `t{id}.gif`, `k{id}.gif`, `q{id}.gif`

### 2.16 varyname=16 合成类

- **使用对象**: 玩家自身
- **前置检查**:
  - 背包未满
  - 需要数据库行锁（`getLock`）
- **Effect 键详解**:

#### `hecheng` 图纸合成
- **格式**: `hecheng:(材料1ID:数量|材料2ID:数量|...):产物1ID:数量|产物2ID:数量`
- **示例**: `hecheng:(956:10|957:10|958:10|1025:1):1012:1|1013:1`
- **流程**:
  1. 检查背包中每种材料数量是否足够
  2. 扣除材料（从数量最少的格子开始扣）
  3. 扣除图纸自身
  4. 生成产物写入背包
- **限制**: 材料不足时报错

#### `chongzhu` 重铸合成
- **格式**: `chongzhu:(材料propId1|材料propId2|...):产物1ID:概率|产物2ID:概率`
- **示例**: `chongzhu:(956|957|958|1025):1012:10|1013:50`
- **流程**:
  1. 从背包中随机选取1个符合条件的材料（`sums=1, zbing=0`）
  2. 按概率决定获得哪个产物（`rand(0,100)` 与概率比较）
  3. 扣除图纸和被重铸的材料
  4. 获得产物（`propscolor==6` 时发系统公告）
  5. 写入 `gamelog` 表记录
- **限制**: 背包中无待重铸物品时报错；重铸失败则材料消失无产物

#### `random_combine` 随机合成
- **格式**: `random_combine:需要propId1,数量|需要propId2,数量;获得propId1,概率,数量,公告|获得propId2,概率,数量,公告`
- **流程**:
  1. 检查每种需要物品的数量是否足够
  2. 对每种获得物品按概率判定（`rand(0,100) <= 概率`）
  3. 只命中第一个概率命中的物品
  4. 扣除需要物品和图纸自身
  5. 获得产物（公告标记 > 0 时发系统公告）
- **限制**: 数量不足时报错；合成失败则材料消失无产物
